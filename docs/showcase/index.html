03 / DESIGN DECISIONS

Make each action
accountable.

The agent chooses its inspection, editing, and checking actions. The runtime binds those actions to source, evidence, and remaining resources.

Δ

Checks follow the diff

A PASS belongs to the exact code that was checked. A subsequent edit requires fresh verification.

Tradeoff: more checks consume time and actions.

Tool gateway ↗
↻

Recovery preserves identity

Action IDs and input hashes distinguish completed work from a new request after interruption.

Tradeoff: uncertain external state stops recovery.

Run journal ↗
≤

Calls need admitted budget

The runtime counts input and checks cost immediately before model dispatch, with zero SDK retries.

Tradeoff: a run may stop before solving the task.
