## Resource and assessment contracts

The unchanged limits are USD 3.50, six generations and six fresh input counts,
60,000 input / fixed 25,000 output tokens per request, 18 tools, two accepted
edits, at most four parallel reads, 281 seconds for the solver including
preparation, and 720 seconds overall. Public terminal diagnosis is once/30s and
isolated evaluation once/330s, both inside the invocation deadline.

The separate I2 collector also checks the solver deadline before credentials
and metadata, and bounds the metadata timeout by the remaining preparation
time. A 282-second preparation cannot start metadata or the solver; at 280
seconds metadata has at most one second. This implements the frozen time limit.

Count six can fund generation six. Already dispatched usage settles even after
the deadline; returned tools still need admission. Edit two permits remaining
checks/finish, never edit three. Parallel reads and automatic repair rechecks
count individually. The existing completion reserve remains: at 16 actions a
two-read batch that would consume the remaining finish capacity is rejected.
There is no rule to spend all 18 slots.

U is sealed from public evidence before both final assessments. Conditional
qualification can count; a correct patch alone cannot prove observable uptake.
The callback cannot cite absent/private events or bypass accepted-edit linkage
for U PASS. Review timeout stops assessment. A normal public behavioral FAIL
can receive the one isolated evaluation; setup, identity, truncation, timeout
or cleanup uncertainty cannot. Neither result starts another model turn.
Resource cutoff does not manufacture a submission or U FAIL.

No retries, protocol corrections, resume, replacement rows, paid compactions,
paid judges or seed-diagnostic execution were added. Unexpected input drift
stops before count/dispatch; no widened normalization or fallback input exists.
