existing drop=first option and has a demonstrated silent-data failure. Grouping
is a separate pre-existing boundary and is not bundled into the first diagnostic.

  Weaken this explanation if a valid zero-width case was actually run and checked.

  masks its defect. Darts B's index mismatch is real, but fixing it did not add the
  missing case; it is insufficient to explain the remaining omission.
- **Source delivery:** the mapping or inverse implementation was unavailable in
  successful tool output. Failed/truncated reads would support this; successful
  receipts weaken this specific explanation without proving model attention.
- **Scope interpretation:** the agent limits validation to ordinary issue examples.
  The public issue asks for actual output-width awareness and public source documents
  inverse transformation, but records cannot reveal the model's internal cause.
