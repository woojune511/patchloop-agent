## Decision and limits

The size split enabled actual execution of both unchanged requests. The original
F0010 symptom was reproduced and distinguished from the init-present control.
However, neither observed JSON value matches the model-authored failure oracle.
This supports caller/symptom reproduction in this pinned environment, not formal
original-obligation acquisition, repair success or general agent improvement.
No fresh model, patch, post-edit replay, required regression or evaluator ran.

The next question is a prospective observation contract focused on the original
F0010 condition, with ordinary lint diagnostics and setup/execution errors recorded
separately. Do not replace the frozen expected value after seeing these results
or retroactively grant acquisition credit. The mismatch is in the authored
observation/expectation, so increasing attempts or loosening completion criteria
is not supported by this result. This two-request allocation is closed.
