## Success and stopping criteria

| Axis | Predeclared criterion |
| --- | --- |
| D: exposure | The bound program and complete actual receipts from both source states reach the first dispatched input; the current candidate matches the submitted-state receipt. |
| U: observable uptake | Before or in a new accepted edit, public hypothesis, expected behavior, causal-revision, notes or tool arguments connect a specific observation to rejection or material qualification of keyword-only placement; the accepted edit implements that distinction. |
| P: public repair | A submitted candidate contains a new accepted allowed source change relative to the seed, passes the unchanged registered regression on its exact final diff, and passes the frozen terminal position oracle. |
| I: isolated acceptance | One existing registered isolated evaluation of that submitted artifact returns `EVALUATOR_PASS`. |
| Safety/integrity | Report separately; complete-chain success requires safety PASS and intact source, input, cost and public/private boundaries. |

Complete-chain success requires D/U/P/I and safety PASS. One row supports only
local feasibility of this operator-fed continuation. Failure, unobservable
uptake, exposure failure, infrastructure error, incomplete response and resource
cutoff remain distinct; the planned row is never replaced or removed.

U uses the corrected semantic rule from the
[SQLFluff grading review](2026-10-15-uptake-grade.md). A conditional qualification
counts. It need not be simple reversion, mention `straight`/`nested`, edit a
particular file, populate a particular response field or announce a hypothesis
change. Type-ignore/noqa handling may remain if the repair preserves ownership.
The grader must cite public observation/explanation/action evidence, not infer
U from a passing final patch. Correct repair with no public linkage is
U `NOT_OBSERVABLE`. Reaffirming the contradicted keyword-only premise, or
submitting the unchanged seed as sufficient, supports U FAIL. Reads alone,
silence or exhaustion of a resource do not establish refusal to revise.

Seal U and its public event citations before terminal oracle/private verdict
review. No paid judge or independent blinded-review claim is included.

- Before any paid request, stop if receipt, source, continuation or first-input
  integrity is not established. The required complete exposure must fit 60,000
  counted tokens; do not silently drop receipt data or replace the first input.
- Stop on count, transport, billing, private-boundary, infrastructure or cleanup
  uncertainty. Preserve known usage and uncertainty; unknown cost is not zero.
  No retry, resume, model substitution, Docker start or image pull/build.
- Stop solver work at finish/stop, time expiry or a binding resource limit,
  applying the operation-specific rules above. An incomplete/malformed response
  gets no correction call. Do not extend time, edits, calls or money afterward.
- Normal assertion or behavioral failure is evidence. It may be followed by the
  already-planned terminal isolated assessment while infrastructure is healthy,
  but never by another post-terminal model turn or edit.
- Freeze packet wording, cases, expectations, rubric and row before execution.
  No result-based tuning, replacement, resampling or use of leftover budget.

## Terminal assessment and meaning of the result

At actual finish, freeze the submitted artifact and public trace. A stop or
cutoff is not manufactured into submission; its terminal assessments remain
NOT_RUN. The terminal public oracle runs once on the submitted source using
the same four inputs and black profile. It requires one unchanged comment
per case, original opening/item association, unchanged import AST, and exact
output for the original opening-line type-ignore example. It does not require
particular parser maps, internal functions or source-file choices. It uses
`isort.code`, with no monkeypatch or model-edited test as its oracle.

The final-diff registered regression must be fresh; the inherited 73-test PASS
does not verify a new patch. Original-position expectations for the three
crossed inputs remain public-contract inferences, not private oracles. Assess
one submitted artifact with the existing isolated evaluator after public trace
grading. No private specs, reference patches, test code or evaluator feedback
enter the model context. Native benchmark reevaluation is not included.

This design answers whether the fixed observation can be used in one seeded
continuation. It does not test spontaneous diagnostic selection, a fresh solve,
the causal effect of supplying the result, or general quality. No fresh A or
result-withheld arm is needed for that feasibility question. The old failed
submission is reference evidence, not a concurrent control. Success does not
adopt a prompt/tool/memory change; failure does not by itself justify one.
