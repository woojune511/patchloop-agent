# Saved caller-panel assessment

`diagnostics.caller_uptake_followup` is a provider-free operator path for a sealed
caller A/B collection whose original post-run assessment stopped before its first
probe. It requires explicit local authorization, an exact original packet hash,
an expected submission count and a fresh external output directory. It never
calls collection, counting, generation or a model-based judge.

The original packet, stopped journal, saved submissions and pre-grade public audit
remain read-only. The new manifest records the original and repaired operator
commits, exact saved patch artifacts, unchanged runtime, inputs and evaluation
budgets. Only the assessment storage owner and native empty-projection handling
may differ among the original implementation bindings. Programs, rubric, task,
source, dependency inventories, images and installed native harness must match.

The shared assessment loop writes each source-only patch through that assessment
folder's ArtifactStore. Containment and atomic-write validation remain enabled.
It restores original tests, verifies the projected diff and applies both frozen
caller programs in common B dependencies, followed by the existing native harness.
The two probes and native assessment share 600 seconds per row; each probe keeps
its original caps and native tests keep the 300-second cap. Errors, uncertain
cleanup or registered/native disagreement stop remaining assessments. There is
no retry or resume into an existing output directory.

A nonempty tests-only submission has an empty source projection after original
tests are restored. Only this operator projection uses the explicit native
`--empty-source-projection` option: an exactly empty patch leaves source unchanged
while still running the complete native assessment. Ordinary empty predictions,
whitespace-only patches and missing predictions remain rejected. This is no
repair credit or acceptance shortcut. Original submission and source projection
hashes are separate evidence.

Results are saved-patch assessments, not additional fresh solves. Preserve all
twelve intended rows for the original comparison, with the two unsubmitted rows
still NOT_RUN. Reuse the sealed evidence-use labels without retrospective changes.
The original study remains stopped; a separate result can complete the missing
assessment axes without rewriting that history or opening a paid allocation.
