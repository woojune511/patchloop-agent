# Public check focus diagnostic

Diagnostic only: three frozen dev-train final-check checkpoints (Pydantic, HF Hub,
Fromager), two independent responses per arm, 12 responses maximum. A uses the
original request, with a common fresh 25K output allowance. B adds only a final user
message repeating every public visible_check definition already in that request.
No handpicked missing case, hidden material, solution or new observation is supplied.
The hypothesis concerns attention to available verification definitions, not missing
information. Repetition/position/length change together; no claim isolates those.

Model gpt-5.4-2026-03-05 xhigh; exact repository .env; new invocation cap $8.
Count immediately before dispatch; 60K input, 25K output, zero SDK retries. Standard
full reservation <=$0.525 per call, <=$6.30 overall at current prices. Use a 30-minute
shared deadline, balanced pair admission and no continuation/replacement. Stop on
count/transport/billing uncertainty. Historical displayed budgets remain unchanged.
No returned tools execute. Acceptance, safety and repair success remain NOT_RUN.

Source journal/CAS, native delivery and exact projections are rechecked before calls.
Old source runtimes are preserved: this is input replay, not old-workspace execution.
No production harness defaults change. Plan and results are external, journal-bound.
User explicitly delegated design/execution without another approval; bind that
instruction to the concrete packet and cap rather than reusing any closed grant.

Before mapping arms, review anonymous public decisions only. Primary rubric: correctly
identifies a concrete applicability/preservation distinction and selects a source
inspection or discriminating probe that can resolve it. More tools or a finish refusal
alone is not improvement. Secondary: unsupported coverage claims, correct limitations,
relevant versus redundant actions, output validity and cost. For Pydantic distinguish
provider opt-in from generic field mode; for HF distinguish explicit client endpoint
from default substitution; Fromager control should preserve graph parent ownership
without inventing a defect. Rubric never enters model context. The same investigator
is an arm-masked reviewer, not an independent blind evaluator. Report all samples,
incomplete cells and per-task outcomes; no pooling into general performance claims.
