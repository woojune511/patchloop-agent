# Post-check time extension

`diagnostics.post_check_extension` freezes the completed public prefix immediately
before the source's unresolved model call. Its latest action must be a passed check.
The whole source, excluded uncertain call, prefix, input, runtime and implementation
are bound. No completed later action/response is allowed. The original journal and
unknown charge remain untouched; the new fork does not reconcile or retry that call.

Restore all accepted mutations in order with exact pre/postimage and cumulative diff
hashes; copy prior checks/history without reexecuting them. Add 3,600 seconds to the
source active limit and replace only the new cost allowance. Keep other counters,
model, source, registered tools, advice-removal behavior and environment unchanged.
Add no review cue, operator observations, private evaluation results or answer hints.
A fresh call from the same decision boundary can incur a charge in addition to the
unknown source charge; report new accounting separately.

`diagnostics.post_check_extension_collector prepare` takes the same packet/env/root/
output flags as the review collector and a positive `--new-cap-usd`. Collection needs
`--approved-manifest-hash` and `--approved-new-cap-usd`. One repetition, single-use
root, zero SDK retries, immediate input count, shared admission ledger and uncertainty
stop. Historical unused funds stay closed. No automatic resume/Docker startup/pull.
The increased whole-run allowance is not infinite; per-call timeout remains bounded
by the available active time. Runtime defaults are unchanged.

Report as a separate official=false continuation, never replace the original NOT_RUN
or call this a matched A/B win. Verify public input delivery and final correctness
separately from successful restoration or submission.
